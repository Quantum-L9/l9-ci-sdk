# Support

## Getting Help

Open an issue in the relevant repository using the appropriate template:

| Issue type | Template |
|---|---|
| Bug report | Bug Report |
| Feature request | Feature Request |
| Governance violation | Gov Violation |
| CI pipeline failure | CI Failure |

Use GitHub Discussions for architecture questions and community input. Security
vulnerabilities must follow `SECURITY.md`, not public issue channels.

## Out of Scope

- General AI/ML questions unrelated to Quantum-L9 infrastructure
- Debugging third-party services without a repository integration defect
- Questions answered by canonical governance documents
- Requests to bypass CI gates or ownership requirements

## Response Expectations

| Channel | Expected response |
|---|---|
| Bugs and governance issues | 2 business days |
| Features | 1 week |
| Discussions | Best effort |
| Security vulnerabilities | Per `SECURITY.md` |
