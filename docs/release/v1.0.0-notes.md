# v1.0.0 — L9 CI SDK contract freeze

**Tag:** `v1.0.0`  
**Package:** `l9-ci` `1.0.0`  
**Semgrep provider lifecycle:** **experimental** (not shadow, not supported)

## What this release is

A frozen **analysis contract** surface for Quantum-L9 CI: provider adapters,
canonical findings/evidence, identity, policy classification library, gate
evaluation library, deterministic bundles, agent projections, and the `l9-ci`
CLI — consumable by `l9-ci-core` via provisioned source/`requirements.txt` or
wheel install.

## Highlights

- Semgrep provider with machine-readable JSON import, explicit identity
  resolution, version policy `>=1.100.0,<2.0.0`
- Runtime-captured Semgrep fixture + full-path integration test
- Gate engine (`pass` / `fail` / `incomplete` / `invalid`); missing required
  evidence ≠ PASS
- Thin `l9-analysis*.yml` callers onto Core `analyze-semgrep.yml` (immutable SHA)
- Dual packaging: `pyproject.toml` + mirrored `requirements.txt`
- Path A release evidence sealed via `docs/release/evidence-map.yaml`

## Known limitations

See [known-limitations.md](./known-limitations.md). Semgrep remains
experimental; coverage may be limited without `paths.scanned`; no OS sandbox.

## Non-claims (do not read into this tag)

- Semgrep is **not** `supported` / GA
- P4 shadow observation is **not** complete
- AUD-008 required-check proofs are resolved (issue #44, ruleset 20147356,
  PRs #45/#46) — see `docs/release/evidence-map.yaml` / `aud008-receipt.json`
- Second provider (P5) is **not** started
