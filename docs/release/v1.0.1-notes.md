# v1.0.1 — L9 CI SDK maintenance release

**Tag:** `v1.0.1` (to be created from the accepted candidate)
**Package:** `l9-ci` `1.0.1`
**Semgrep provider lifecycle:** **experimental** (unchanged — not shadow, not supported)

## What this release is

A **maintenance / patch** release over `v1.0.0`. It carries release-integrity
and tooling-hygiene corrections only. There is **no change to the public API,
the canonical bundle contract, the CLI surface, or the integration contract**
(`l9.integration-contract/v1`), so consumers of `v1.0.0` require no changes.

## Changes

- **Tooling pin alignment (issue #50):** the `ruff-pre-commit` hook rev is bumped
  from `v0.15.5` to `v0.16.0` so the pre-commit Ruff matches the exact
  `ruff==0.16.0` pin in `requirements-ci.txt`. `ruff.toml` already pinned the
  rule set; this closes the residual **binary-version** drift across the 0.15.x
  and 0.16.0 families so `ruff check` / `ruff format --check` are deterministic
  regardless of which Ruff a runner resolves.
- **Publishing mechanics (already on `main`, #49):** `publish.yml` publishes via
  the GitHub `pypi` environment token, resolving the `v1.0.0` Trusted-Publisher
  `invalid-publisher` path. This release is published by the repository-owned
  tagged workflow.
- **Release-integrity documentation:** AUD-008 required-check proofs remain sealed
  (see `docs/release/evidence-map.yaml` and `aud008-receipt.json`).

## Migration

**None required.** No public API, bundle, schema, or CLI change since `v1.0.0`.
Pinned consumers can move from `1.0.0` to `1.0.1` with no code or contract change.

## Known limitations

See [known-limitations.md](./known-limitations.md). Semgrep remains
**experimental**; a supported-provider release is a separate, evidence-gated
lifecycle step and is **not** part of this maintenance release.

## Non-claims (do not read into this tag)

- Semgrep is **not** `shadow` or `supported` — lifecycle state is unchanged.
- No second provider, repair loop, or hosted capability is introduced.
- The `MANIFEST.md` inventory is reconciled by `l9-manifest-reconcile.yml` on the
  pull request; it is not hand-maintained in this note.

## Install

```bash
pip install "l9-ci==1.0.1"
l9-ci providers list
# → Semgrep state: experimental
```

- PyPI: https://pypi.org/project/l9-ci/1.0.1/ (after publication)
- GitHub Release: created only after PyPI publication is verified.

## Rollback

- `v1.0.0` and PyPI `l9-ci 1.0.0` are immutable and are **never moved, deleted,
  recreated, or replaced**.
- To revert a consumer: `pip install "l9-ci==1.0.0"`.
- If a corrective source change is required after tagging, cut a new patch
  (`v1.0.2`) — do **not** move the `v1.0.1` tag or replace the `1.0.1` PyPI files.
